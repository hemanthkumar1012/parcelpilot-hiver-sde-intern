# Data boundary

Put assessment/sample data here when it is legally appropriate to commit it.

Expected runtime layout:

```text
data/
  raw/
    *.xlsx
  processed/

knowledge_base/
  policies/
    *.pdf
  sop/
    *.pdf
```

Do not commit credentials, private customer information, or files whose assessment license forbids redistribution.

The application deliberately reports when the data assets are absent instead of fabricating records.
